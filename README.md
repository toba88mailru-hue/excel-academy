# Excel Academy

Рабочий интерактивный прототип корпоративной платформы обучения Microsoft Excel. Откройте `index.html` локально или используйте GitHub Pages.

## Что реализовано в прототипе

- две демонстрационные роли: сотрудник и куратор/администратор;
- вход через персональную ссылку в демонстрационном режиме;
- 4 последовательных уровня, 60 тематических уроков и блокировка следующих уровней;
- уроки с целью, теорией, пошаговым примером, формулой, ошибками, заданием, вопросами, тренажёром и загрузкой XLSX;
- входной тест с автоматическим определением стартового уровня;
- библиотека с поиском, уроками и открытыми источниками;
- ИИ-куратор с контекстными подсказками;
- реестр сотрудников, карточка сотрудника, создание приглашений и имитация массового импорта;
- аналитика, уведомления, дедлайны, отчёт CSV, CMS-контент и банк вопросов.

## Важное ограничение демонстрационной версии

GitHub Pages — статический хостинг. Поэтому вход, роли, данные сотрудников, приглашения, проверки XLSX и ИИ в этом прототипе имитируются в браузере и сохраняются только в `localStorage`. Для реального корпоративного запуска необходим серверный контур: Moodle либо backend с PostgreSQL, корпоративный SSO, API для проверки файлов, хранилище медиа, журнал действий и role-based access control.

## Бесплатная архитектура пилота

- Moodle на локальном сервере: роли, курсы, задания, тесты и отчётность;
- PostgreSQL/MariaDB: защищённые данные;
- Ollama с локальной моделью: ИИ-куратор без оплаты API;
- Python + aiogram: Telegram-уведомления;
- Nginx + HTTPS: безопасный внешний доступ.
