# Excel Академия — интерактивный прототип

Откройте `index.html` в любом современном браузере. Сервер, аккаунт или установка не требуются.

В прототипе можно пройти адаптивный тест, увидеть назначенный уровень, открыть урок, имитировать загрузку XLSX-файла, задать вопрос ИИ-куратору и выгрузить демонстрационный отчёт администратора в CSV.

## Бесплатная архитектура для пилота на 10 сотрудников

* **Moodle** на локальном сервере: курсы, роли, тесты, загрузка заданий и отчётность.
* **Ollama + Qwen / Llama** на том же сервере: бесплатный локальный ИИ-куратор. Качество зависит от железа; для комфортной работы желательно от 16 ГБ RAM.
* **Python + aiogram**: Telegram-бот с webhook/API Moodle.
* **PostgreSQL / MariaDB**: база Moodle; резервное копирование по расписанию.

Для реального запуска понадобятся сервер, домен с HTTPS для Telegram-webhook и согласование обработки персональных данных. Прототип не передаёт и не хранит реальные данные.
